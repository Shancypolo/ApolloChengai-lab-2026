# Trail Recommender

Ask for a hiking area and a few preferences. The program searches trail sources and suggests close matches.

PowerShell:

```powershell
$env:OPENAI_API_KEY = "your-key"
py -X utf8 trail_recommender.py
```

Install dependency:

```powershell
py -m pip install -r requirements.txt
```

Answer naturally. You can use any language supported by your terminal. Use a broad area instead of a home address.
